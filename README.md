# Interactive Dashboard (Power BI)

## Project Overview

This project is an interactive Power BI dashboard developed to analyze
and visualize business data using meaningful KPIs, charts, and filters.
The dashboard helps users understand trends, compare performance
metrics, and make data-driven decisions.

## Features

-   Interactive dashboard design
-   KPI cards and summary metrics
-   Data visualization using charts and graphs
-   Filtering and slicing options
-   Business insights and trend analysis
-   User-friendly report layout

## Tools Used

-   Power BI
-   Power Query
-   DAX
-   Microsoft Excel / CSV datasets

## Dashboard Components

-   KPI Cards
-   Charts and Graphs
-   Slicers and Filters
-   Comparative Analysis
-   Trend Analysis

1.  Download the `.pbix` file.
2.  Open it in Power BI Desktop.
3.  Refresh the data if required.
4.  Explore the dashboard using the filters and visuals.
